Langkah 2: Siapkan Sprite Emoji 🎨

😐

Costume 1:
not sure

😢

Costume 2:
sad

😄

Costume 3:
happy

Buatlah satu Sprite baru (gambar sendiri) berupa wajah emoji.
Pastikan nama kostumnya benar: not sure, sad, dan happy.

Langkah 3: Rangkai Kode Sprite! 🧩

when clicked
switch costume to not sure ▾
ask type a message and wait
if ML recognise text answer (label) = ML bad_words then
switch costume to sad ▾
if ML recognise text answer (label) = ML good_words then
switch costume to happy ▾

Penjelasan:

  1. Reset wajah ke not sure.
  2. Tanya perasaan user lewat box ketikan.
  3. AI akan mengecek apakah jawabanmu termasuk bad_words atau good_words.
  4. Wajah berubah sesuai hasil analisa AI!

Waktunya Testing! 🧪

💭⌨️

Klik bendera hijau, lalu ketikkan sesuatu di kolom Ask. Lihat respon wajah emojimu!

Bagaimana jika AI salah menebak?

Itu tandanya Datasets (contoh kata) kita masih kurang banyak! Robotnya belum pernah mendengar kata itu sebelumnya, jadi dia menebak asal.

Ayo Buat AI-mu Lebih Cerdas! 🚀

📈📚🤖

Jika AI-mu masih sering salah, kembalilah ke tab Train di ML4K. Tambahkan 10-20 contoh kata lagi untuk setiap label!

Data adalah nutrisi untuk otak robot! Semakin banyak data, semakin cerdas!
